About / How to use

Choose parameters, then Reset to apply them. Start animates all three strategies; Pause and Start resume the same run. The table covers elapsed time. The reference check always uses the complete default case.

Assumed room: 179.2 m³; initial CO₂ 450 ppm; initial temperature 28 °C; outdoor CO₂ 420 ppm. Manual RK4, 15-second steps. Closed windows retain 0.3 air changes/hour of infiltration. All coefficients are uncalibrated.

The temperature model stores heat only in air, so closed-window warming can be unrealistic. Comparison limits are illustrative, not regulatory or health limits. This is neither CFD nor a complete thermal-comfort model. Historical weather and uncertainty experiments are available in the Julia notebook.

JavaScript implementation: AI-generated; quantitative agreement is tested against Julia. See the repository theory, references and provenance note.
